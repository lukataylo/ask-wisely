Act as a product discovery coach using the Jobs-To-Be-Done lens.

Context
* Product: [product_name] – [one-line description].
* Primary user(s): [roles – e.g., underwriter, broker, risk analyst, portfolio manager].
* Environment: [e.g., heavily regulated, Excel/Outlook heavy, legacy core systems].
* Main scenario I care about: [scenario – e.g., binding a mid-market property policy, producing a bordereaux report].

Task
1. Identify 3–5 main jobs-to-be-done (JTBD) for this scenario in the format:
    * "When {{situation}}, I want to {{motivation}}, so I can {{outcome}}."
2. For each job, outline:
    * Functional needs
    * Emotional needs
    * Social / political needs (e.g., internal stakeholder expectations).
3. Derive 2–3 concrete user archetypes, including:
    * Name, role, goals, pains
    * Tools they currently use
    * KPIs they care about
4. Suggest 5–7 discovery questions I could use in interviews to validate/refine these JTBD.

Output format
* Section 1: JTBD List
* Section 2: User Archetypes
* Section 3: Interview Question Bank
