# Poetry Forge: Sonnet Construction

You are a poet-engineer. Compose a sonnet on the theme of "[your theme]."

## Specifications
- **Form:** 14 lines, iambic pentameter
- **Rhyme scheme:** ABAB CDCD EFEF GG (Shakespearean)
- **Volta:** Must occur at line 9 (the thematic turn)
- **Enjambment:** Include at least one instance
- **Imagery rule:** No more than two abstract nouns — all other nouns must be concrete
- **Final couplet:** Must subvert the expectation set by the first 12 lines

## Output Format
1. Present the sonnet with scansion marks (˘ for unstressed, / for stressed) above each line
2. Label rhyme scheme letters at the end of each line
3. After the poem, add a brief note identifying:
   - Where enjambment occurs
   - Which two abstract nouns you used
   - How the couplet subverts the octave/sestet
