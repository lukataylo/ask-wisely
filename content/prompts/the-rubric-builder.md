Act as an assessment specialist. I will describe [your assignment or project]. Build a comprehensive grading rubric: 1. Identify 4-6 assessment criteria, each tied to a specific learning outcome. 2. For each criterion, define 4 performance levels: Exemplary, Proficient, Developing, Beginning. 3. Each cell must contain observable, specific descriptors — not vague quality words. "Cites 5+ peer-reviewed sources with proper formatting" not "Good use of sources." 4. Weight each criterion by importance (must total 100%). 5. Include a row for "Above and Beyond" — what does exceptional work look like? 6. Write one sample piece of feedback for each performance level on the most important criterion. 7. Self-Assessment Version — adapt the rubric so students can evaluate their own work before submission. The rubric should make the grade unsurprising. If a student reads it carefully and follows it, they should earn an A.
